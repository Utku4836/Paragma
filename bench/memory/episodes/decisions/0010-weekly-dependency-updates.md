# 0010: Weekly dependency updates

## Context
We needed a consistent answer for weekly dependency updates across the API and the admin tools.

## Decision
Weekly dependency updates. Revisit if it starts to cost more than a day per quarter.

## Alternatives
- Keep the status quo: inconsistent between services.
- A heavier tool: not justified at our size.
