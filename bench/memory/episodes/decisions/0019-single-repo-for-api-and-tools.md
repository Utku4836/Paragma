# 0019: Single repo for API and tools

## Context
We needed a consistent answer for single repo for api and tools across the API and the admin tools.

## Decision
Single repo for API and tools. Revisit if it starts to cost more than a day per quarter.

## Alternatives
- Keep the status quo: inconsistent between services.
- A heavier tool: not justified at our size.
